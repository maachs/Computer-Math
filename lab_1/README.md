# Лабораторная №1. Численное дифференцирование

Пять разностных схем для производных пяти функций; сравнение погрешности при уменьшении шага.

## Запуск

Откройте [lab.ipynb](lab.ipynb) и выполните **Restart Kernel and Run All Cells**.
Установка зависимостей описана в [корневом README](../README.md).

## Параметры

Точка `x0` задаётся в начале тетради. По умолчанию `x0 = 2`.

## Структура

- `lab.ipynb` — задача, параметры, теория и методы, расчёты и графики, проверки.
- `materials/` — исходные материалы и дополнительные пояснения.

Результаты сохраняются внутри тетради. Отдельные файлы автоматически не создаются.
