# Лабораторные работы по вычислительной математике

Самостоятельные тетради Jupyter с обычными функциями, комментариями и проверками.

| Работа | Тема | Тетрадь |
| --- | --- | --- |
| №1 | Численное дифференцирование | [lab_1/lab.ipynb](lab_1/lab.ipynb) |
| №2 | Решение СЛАУ девятью методами | [lab_2/lab.ipynb](lab_2/lab.ipynb) |
| №3 | Стационарная теплопроводность и тепловая надпись «РТ» | [thermal_letters/lab.ipynb](thermal_letters/lab.ipynb) |

## Запуск

Нужен Python 3.10 или новее. Из корня проекта выполните:

```bash
python -m pip install -r requirements.txt
python -m jupyterlab
```

Откройте нужную тетрадь, выберите ядро Python 3 и выполните
**Restart Kernel and Run All Cells**. Можно также использовать VS Code с расширением Jupyter.
Если Python запускается командой `python3`, используйте её.

## Единая структура

В каждой папке работы (`lab_N` или `thermal_letters`) находятся:

- `README.md` — краткое описание, запуск и параметры.
- `lab.ipynb` — весь код, результаты и графики.
- `materials/` — задания, исходные данные и дополнительные заметки.

Во всех тетрадях одинаковые разделы: постановка задачи, библиотеки и параметры,
теория и методы, расчёты и графики, проверка реализации.
Исходные параметры меняются в начале. Графики и результаты остаются внутри
тетрадей; дополнительные файлы автоматически не создаются.
