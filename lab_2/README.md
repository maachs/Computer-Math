# Лабораторная №2. Решение СЛАУ

Девять методов решения системы `Ax = f` и сравнение сходимости по невязке.

## Запуск

Откройте [lab.ipynb](lab.ipynb) и выполните **Restart Kernel and Run All Cells**.
Установка зависимостей описана в [корневом README](../README.md).

## Параметры

Матрица `A` и вектор `f` задаются в начале тетради. По умолчанию выбран вариант «м».
Для примера из TXT укажите `system_file = "system.txt"`.

## Структура

- `lab.ipynb` — задача, параметры, теория и методы, расчёты и графики, проверки.
- `materials/` — исходные материалы и дополнительные пояснения.
