# Стационарная теплопроводность и тепловая надпись «РТ»

Лабораторная №3: уравнение Лапласа в квадрате и распределение температуры
в комнате с обогревателями и окнами, образующее надпись «РТ».

## Запуск

Откройте [lab.ipynb](lab.ipynb) и выполните **Restart Kernel and Run All Cells**.
Установка зависимостей описана в [корневом README](../README.md).
Обе задачи полностью находятся в этой тетради.

## Параметры

Исходные данные находятся в разделе «Библиотеки и параметры».

- `square_*` — сторона квадрата, граничные значения, сетка и относительный допуск.
  По умолчанию: 0.1 м, значения 1, 2, 3, 4, `T = 100u`, 20 интервалов, допуск `1e-9`.
- `room` — размеры комнаты, температуры стен, теплопроводность и потери тепла.
  По умолчанию комната имеет размеры 10 × 6 м.
- `heater_temperature`, `stroke_width` — температура и толщина полос: 65 °C и 0.18 м.
  `custom_heaters = None` включает «РТ», список задаёт свои приборы, `[]` отключает их.
- `windows` — список участков стен с заданной температурой. По умолчанию два окна
  по 5 °C; значение `[]` отключает окна.
- `nx`, `ny`, `tolerance`, `max_iterations`, `omega` — сетка комнаты,
  абсолютный допуск нормированной невязки, лимит итераций и параметр SOR.

Координаты объектов задаются в метрах. Схема букв масштабируется вместе с
комнатой; координаты окон и собственных обогревателей остаются абсолютными.

## Структура

- `lab.ipynb` — задача, параметры, теория и методы, расчёты и графики, проверки.
- `materials/` — исходное задание и дополнительные пояснения к модели.

Тетрадь содержит методы Якоби, Зейделя и SOR, ряд Фурье, изолинии и сечения,
сгущение сетки, исследование релаксации и проверки. В задаче комнаты сравниваются
варианты с потерями тепла и без них. Код оформлен обычными функциями без классов.

Результаты и графики сохраняются внутри тетради. Отдельные файлы автоматически
не создаются. Пояснения написаны на русском, код и программный вывод — на английском.

## Презентация и анимация

[Презентация в PDF](../output/pdf/thermal_letters.pdf): 24 слайда о методах,
сходимости и погрешностях со всеми 11 графиками тетради.

[GIF установления температуры](../output/gif/thermal_letters.gif): нагрев комнаты
с начальной температурой свободных узлов 18 °C. Температуры стен, окон и полос
фиксированы. Условная теплоёмкость слоя 1000 Дж/(м²·К) задаёт время на кадрах.
Анимацию открывайте отдельным файлом, PDF содержит только статичные кадры.

Для повторной сборки выполните из корня репозитория:

```bash
python -m pip install -r thermal_letters/materials/requirements_artifacts.txt
python thermal_letters/materials/prepare_artifacts.py
python thermal_letters/materials/build_presentation.py
```

Промежуточные графики записываются в `tmp/pdfs/thermal_letters/assets/`,
готовые PDF и GIF — в `output/`. Сборщик PDF по умолчанию использует шрифты
Arial из `C:/Windows/Fonts`; для другой системы задайте `--font-directory`
с файлами `arial.ttf`, `arialbd.ttf`, `ariali.ttf`.

Для динамики используются явный Эйлер и центральные разности с устойчивым шагом.
Сборщик проверяет граничные значения, пределы температуры, постоянное решение,
совпадение с SOR и различие результатов для шагов `dt` и `dt/2`.
