# Лабораторная №3. Стационарная теплопроводность

Уравнение Лапласа в квадрате методами Якоби, Зейделя и SOR.

## Запуск

Откройте [lab.ipynb](lab.ipynb) и выполните **Restart Kernel and Run All Cells**.
Установка зависимостей описана в [корневом README](../README.md).

## Параметры

Параметры задаются в начале тетради: сторона 0.1 м, границы 1, 2, 3 и 4; `T = 100u`.
По умолчанию используется 20 интервалов по стороне и допуск `1e-9`.

## Структура

- `lab.ipynb` — задача, параметры, теория и методы, расчёты и графики, проверки.
- `materials/` — исходные материалы и дополнительные пояснения.
